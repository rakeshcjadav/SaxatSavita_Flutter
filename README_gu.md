## 🌟 પરિચય

સાક્ષાત્ સવિતા એ Flutter એપ છે, જેમાં ગ્રંથ ઑફલાઇન વાંચી શકાય. એપની ભાષા અંગ્રેજી અને ગુજરાતી છે; કિરણનું મૂળ પાઠ ગુજરાતીમાં જ રહે છે. વાંચન સાથે પ્રગતિ, નોંધ, શોધ, સત્સંગના હરિભક્તો, વિચરણના નકશા, આજનો ઉપદેશ અને કિરણ વાંચ્યા પછીનો પ્રશ્નોત્તર પણ છે.

## ✨ મુખ્ય લક્ષણો

### 📚 **વાંચન**
- **સંપૂર્ણ ગ્રંથ**: પાંચેય ભાગ અને ૬૯૭ કિરણો, ઑફલાઇન ઉપલબ્ધ
- **કિરણની માહિતી**: ગુજરાતી તારીખ, ગામ અને સ્થળ, શિક્ષણ, સારાંશ અને ઇતિહાસ — વાંચન પૃષ્ઠ અને કિરણ યાદીમાં
- **ગામ પ્રમાણે ફિલ્ટર**: યાદી અને કૅલેન્ડર ગામ પ્રમાણે સાંકડા કરો
- **કૅલેન્ડર અને ક્રમ**: તિથિ/તારીખ અને સમયક્રમ પ્રમાણે કિરણો જુઓ
- **શોધો**: શીર્ષક અને પાઠમાં બહુ-શબ્દ શોધ, હરિભક્તના નામ સાથે મેળ
- **મનપસંદ અને બુકમાર્ક**: કિરણ ચિહ્નિત કરો અને છેલ્લી જગ્યાએ પાછા જાઓ
- **સાંભળો**: ટેક્સ્ટ-ટુ-સ્પીચ (અવાજ અને ઝડપ સેટિંગ્સમાં), અને જ્યાં રેકોર્ડેડ ઑડિયો હોય ત્યાં તે પણ
- **વાંચન સગવડ**: વાંચન અક્ષરની સાઇઝ, એપ અક્ષરની સાઇઝ, લાઇન હાઇટ, સ્ક્રીન ચાલુ રાખો, કિનારી નેવિગેશન, લાઇટ/ડાર્ક થીમ અને રંગ યોજના

### 🧭 **સ્થળો અને હરિભક્તો**
- **હરિભક્તો**: યજમાન, વાંચનાર, પૂછનાર અને વાતમાં આવેલા નામ જુઓ; નામથી શોધો; કિરણની સંખ્યા પ્રમાણે ગોઠવો
- **કિરણમાં**: નામ પ્રકાશિત થાય છે; ચિપ દબાવતાં પાઠમાં તે વ્યક્તિ મળે, લાંબા સમય દબાવતાં પ્રોફાઇલ અને પ્રશ્નો ખુલે
- **વિચરણ નકશો**: OpenStreetMap પર યાત્રાઓ, ઘર તરીકે પીપળાણા દીક્ષાધામ, આવન માર્ગ અને સત્સંગની વિગત
- **સ્થળ નકશો**: ગામો જુઓ અને નકશામાંથી કિરણ ખોલો

### 🧠 **પ્રશ્નોત્તર**
- **આજનો ઉપદેશ**: આખા ગ્રંથમાંથી પાંચ પ્રશ્નો (એક જ કિરણમાંથી નહીં). વિકલ્પો ફેરવાય છે; જવાબ પછી મૂળ કિરણ દેખાય છે
- **હોમ અને ડેશબોર્ડ**: આજનો પ્રશ્નોત્તર પૂરો થાય ત્યાં સુધી હોમ પર શોર્ટકટ; ડેશબોર્ડ પર ગુણ અને અગ્રણી યાદી
- **દૈનિક અને સાપ્તાહિક અગ્રણી યાદી**: દરેક હરોળ પર ક્રમાંક; પહેલા ત્રણ માટે સોનું, ચાંદી અને કાંસાની ટ્રોફી
- **ધારા અને યાદ અપાવવું**: દૈનિક પ્રશ્નોત્તરની ધારા, અને પસંદ કરેલા સમયે સ્થાનિક રિમાઇન્ડર
- **કિરણ પ્રશ્નોત્તર**: કિરણ વાંચ્યા પછી ત્રણ રેન્ડમ ગુણવાળા પ્રશ્નો, પછી ઇચ્છા હોય તો વધુ અભ્યાસ. દરેક કિરણે એક જ ગુણવાળો પ્રયાસ; સાઇન ઇન હોય તો ગુણ સિંક થાય
- **ઑફલાઇન**: ઇન્ટરનેટ હોય ત્યારે Firebaseમાંથી બૅંક, નહીં તો એપમાં રહેલો બૅકઅપ

### 🏠 **હોમ, ડેશબોર્ડ અને નેવિગેશન**
- **ડેશબોર્ડ**: સમય પ્રમાણે અભિવાદન, વાંચન ધારા, આંકડા, ચાલુ યોજના, તાજેતરની પ્રવૃત્તિ, આજનો ઉપદેશ અને ઝડપી ક્રિયાઓ
- **નીચેની પટ્ટી**: ડેશબોર્ડ, પુસ્તક (હોમ), નોંધ, પૂર્વ વાંચન, પ્રોફાઇલ — પસંદ થયેલી ટૅબ અલગ દેખાય
- **સ્વાગત!**: પહેલી વખત મુખ્ય સ્ક્રીનોની ફેરી
- **હોમ સ્ક્રીન વિજેટ** (Android અને iOS): આજનો વાંચન સમય, વંચાયેલાં કિરણો, ધારા અને પ્રગતિ પટ્ટી

### 📝 **નોંધ, યોજના અને અવતરણો**
- **નોંધ**: કિરણ સાથે જોડાયેલી સમૃદ્ધ લખાણ (Quill)
- **વાંચન યોજનાઓ**: દૈનિક લક્ષ્ય (સમય અથવા કિરણ), રિમાઇન્ડર અને સીમાચિહ્ન
- **પૂર્વ વાંચન**: સત્ર, ટાઇમર અને પૂર્ણતા
- **અવતરણ છબીઓ**: ટેમ્પલેટ, ફોન્ટ, ગ્રેડિયન્ટ, સ્ટિકર, ગૅલરીમાં સાચવો અને શેર કરો

### 🙏 **આશીર્વચન અને માહિતી**
- **આશીર્વચન**: આશીર્વચન સંગ્રહ
- **માહિતી**: પ્રસ્તાવના અને ગ્રંથની અન્ય પ્રારંભિક માહિતી

### ☁️ **ખાતું અને સિંક**
- **સાઇન ઇન**: Google અથવા Apple, અથવા મહેમાન તરીકે ચાલુ રાખો (કેટલીક વસ્તુઓ ફક્ત સાઇન ઇન ડ્રૉયરમાં)
- **પ્રોફાઇલ**: નામ અને સ્થળ, ડેશબોર્ડના અભિવાદનમાં વપરાય
- **ક્લાઉડ સિંક**: સાઇન ઇન હોય ત્યારે નોંધ, પ્રગતિ, યોજના, પ્રશ્નોત્તર પરિણામ અને ગુણ બધા ઉપકરણો પર
- **Play Store અપડેટ**: એપમાં અપડેટની સૂચના, જરૂર પડે તો સ્ટોર ખુલે
- **Remote Config**: સ્ટોરની રાહ વગર લક્ષણ ચાલુ/બંધ (જેમ કે દૈનિક પ્રશ્નોત્તર)

## 🏗️ આર્કિટેક્ચર

### ટેક સ્ટૅક
- **ફ્રન્ટએન્ડ**: Flutter 3.7.2+
- **બૅકએન્ડ**: Firebase (Auth, Firestore, Remote Config, Analytics)
- **સ્થાનિક સંગ્રહ**: SharedPreferences — સેટિંગ્સ, કૅશ અને ઑફલાઇન પ્રશ્નોત્તર
- **પ્રમાણીકરણ**: Firebase Auth, Google અને Apple સાથે
- **નકશા**: flutter_map દ્વારા OpenStreetMap
- **વાણી**: flutter_tts અને just_audio
- **વિજેટ**: home_widget (Android + iOS)
- **સૂચના**: flutter_local_notifications (યોજના અને દૈનિક પ્રશ્નોત્તર રિમાઇન્ડર)

### પ્રોજેક્ટ માળખું
```
lib/

├── widgets/                 # અગ્રણી યાદી, કિરણ માહિતી, પ્રશ્નોત્તર UI
└── main.dart

assets/
├── book/                    # કિરણો, પ્રશ્નોત્તર, હરિભક્ત અને નકશાનો ડેટા

├── res/                     # છબીઓ
└── stickers/                # અવતરણ સ્ટિકર
```

## 🚀 શરૂઆત

### જરૂરિયાતો
- Flutter SDK (૩.૭.૨ કે તેથી ઊંચું)
- Android Studio / VS Code
- Firebase પ્રોજેક્ટ
- Android/iOS ડેવલપમેન્ટ વાતાવરણ

### ઇન્સ્ટોલેશન

1. **રિપોઝિટરી ક્લોન કરો**
   ```bash
   git clone https://github.com/rakeshcjadav/SaxatSavita_Flutter.git
   cd SaxatSavita_Flutter
   ```

2. **ડિપેન્ડન્સી ઇન્સ્ટોલ કરો**
   ```bash
   flutter pub get
   ```

3. **Firebase ગોઠવણ**
   - Firebase પ્રોજેક્ટ બનાવો
   - Android/iOS એપ ઉમેરો
   - `google-services.json` (Android) અને `GoogleService-Info.plist` (iOS) પ્લેટફૉર્મ ફોલ્ડરમાં મૂકો
   - Authentication (Google, Apple), Firestore, Analytics અને Remote Config ચાલુ કરો
   - નિયમો `firestore.rules`માંથી ડિપ્લોય કરો (હાથે લખેલો અધૂરો નિયમ ન વાપરો)

4. **એપ ચલાવો**
   ```bash
   flutter run
   ```

### રિલીઝ બિલ્ડ

**Android APK:**
```bash
flutter build apk --release
```

**Android App Bundle:**
```bash
flutter build appbundle --release
```

**iOS:**
```bash
flutter build ios --release
```

## 📱 લક્ષણો વધુ વિગતે

### કિરણ વાંચવું
- ભાગ ખોલો, ગામ અથવા મનપસંદથી ફિલ્ટર કરો, પછી સત્રના સમય સાથે વાંચો
- કિરણની માહિતી: તારીખ, સ્થળ માર્ગ, શિક્ષણ, સારાંશ અને સંબંધિત ઇતિહાસ
- સત્સંગમાં હરિભક્ત ચિપ; દબાવતાં પાઠમાં જાઓ
- ઓછામાં ઓછું એક વાર વાંચ્યા પછી કિરણ પ્રશ્નોત્તર લો

### આજનો ઉપદેશ
- આખા ગ્રંથમાંથી પાંચ ગુણવાળા પ્રશ્નો
- જવાબ પછી મૂળ કિરણ જુઓ અને ખોલો
- અગ્રણી યાદી માટે દિવસે એક વાર પૂરું કરો; પછી પણ સમીક્ષા કરી શકાય
- સેટિંગ્સમાંથી વૈકલ્પિક સ્થાનિક રિમાઇન્ડર

### નકશા
- કૅલેન્ડરના દિવસો સ્થળ સાથે જોડાય છે
- વિચરણ યાત્રા પીપળાણા દીક્ષાધામને ઘર માનીને માર્ગ દોરે છે
- સ્ટોપ દબાવતાં તે કિરણ ખુલે છે

### અનુકૂલન
- **વાંચન** અને **એપ UI**ની અક્ષર સાઇઝ અલગ
- Material 3 લાઇટ/ડાર્ક, રંગ, વેરિયન્ટ અને કૉન્ટ્રાસ્ટ
- અંગ્રેજી અથવા ગુજરાતી ઇન્ટરફેસ (કિરણનું પાઠ ગુજરાતીમાં જ રહે)

## 🔧 ગોઠવણ

### Firebase
1. [Firebase Console](https://console.firebase.google.com) પર પ્રોજેક્ટ બનાવો
2. Authentication, Firestore, Analytics અને Remote Config ચાલુ કરો
3. રિપોઝિટરીની `firestore.rules` વાપરો અને પ્રોજેક્ટના ડિપ્લોય સ્ક્રિપ્ટથી ડિપ્લોય કરો

### હોમ વિજેટ
- **iOS**: App Group `group.com.saxatsavita.flutter.widgets`, URL scheme `saxatsavita://` — `docs/IOS_WIDGET_SETUP.md` જુઓ
- **Android**: એપ મોડ્યૂલમાં `ReadingProgressWidget`

1. **પહેલી શરૂઆત**: સ્વાગત ફેરી, પછી Google અથવા Appleથી સાઇન ઇન, અથવા મહેમાન તરીકે ચાલુ
2. **ડેશબોર્ડ**: અભિવાદન, ધારા, આજનો ઉપદેશ અને શોર્ટકટ
3. **પુસ્તક**: પાંચ ભાગ → કિરણ યાદી → વાંચો, સાંભળો, નોંધ, માહિતી, પ્રશ્નોત્તર
4. **શોધ / હરિભક્તો**: ઉપદેશ અથવા વ્યક્તિ શોધો
5. **નકશો અને કૅલેન્ડર**: વિચરણ અનુસરો અથવા «આ જ દિવસે»
6. **યોજના અને પૂર્વ વાંચન**: દૈનિક લક્ષ્ય રાખો અને સત્ર જુઓ
7. **અવતરણો**: ટેમ્પલેટ અને સ્ટિકરથી શેર કરી શકાય તેવી છબી બનાવો

5. Pull Request ખોલો

### આવૃત્તિ ૨.૪૯.૦ (હાલની)
- **ડેશબોર્ડ અને દેખાવ**: આઉટલાઇન કાર્ડ, ચુસ્ત ડ્રૉયર હેડર, પસંદ થયેલી નીચેની ટૅબ અલગ
- **આજનો ઉપદેશ**: આખા ગ્રંથનો દૈનિક પ્રશ્નોત્તર, રિમાઇન્ડર, પૂરું થાય ત્યાં સુધી હોમ પર બટન, ક્રમાંક અને મેડલ સાથે દૈનિક/સાપ્તાહિક અગ્રણી યાદી
- **કિરણ પ્રશ્નોત્તર**: બધા કિરણો માટે Firestore બૅંક; ત્રણ ગુણવાળા પ્રશ્નો પછી વૈકલ્પિક અભ્યાસ; સિંક થતા ગુણ
